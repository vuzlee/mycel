Add a tool to the analyst

  • A tool is a function the model may call
  • Six files, in this order

Words

WordMeans
toola function the model may call by name
analystthe agent that answers questions over data
promptthe instructions that tell the model the tool exists
schemathe arguments the tool takes, as the model sees them
toolseta group of tools offered to the model together
chipa source the person ticks under the chat box (Jira, Mail…); a toolset opens only for its chips
ModelRetryan error the model reads and can fix by calling again
READY_READSanswers the app already knows how to compute; the model calls one instead of writing SQL
MCPModel Context Protocol: a standard way to call tools that live on another server

Files to change, in order

#FileDo
1agents/tools/work.pyadd @toolset.tool(name=…) inside build_toolset(); a new module copies compute.py
2agents/core/guards.pyuse, do not edit: call guard_repeat(ctx, …) first in a tool the model may repeat (see tools/query.py); the work.py reads skip it; raise ModelRetry for bad input
3agents/specialists/analyst.pyadd the toolset in toolsets(); a ready-made answer also goes in READY_READS (work.py)
4agents/prompts/analyst.pytell the model when to use it
5config/agents/analyst.yamlraise tool_calls_limit if needed — and the "twelve queries" line in the prompt
6web/src/lib/toolLabel.tsa label for the live step, else it shows "Running my tool"
testtests/test_work_tools.pybehaviour; chip in tests/test_chips.py; ready read in tests/test_analyst.py

WayWhere

MistakeResult
