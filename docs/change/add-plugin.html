02 · Checklist

  • Register the callback <PUBLIC_BASE_URL>/auth/<key>/callback at the provider.
  • toolsets(role) returns [] when not configured(); import tool modules inside it.
  • Tools carry chip metadata (opens(...)), or the chip filter hides them.
  • syncs = False unless data is copied; then sync() reads on people's tokens only.
  • probe() raises on a broken state; returns one line otherwise.
  • Add the setup steps to docs/operate/setup.md.

03 · Tests to add

  • Unconfigured → no toolsets (see tests/test_plugin_tools.py).
  • /auth/plugins lists the new key (tests/test_auth.py).
  • If it syncs: a revoked token is skipped (tests/test_sync_readers.py).
