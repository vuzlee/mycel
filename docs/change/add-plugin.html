Add a plugin

  • A provider each person connects, e.g. GitHub
  • One folder: client, consent, plugin; one registry line

Words

WordMeans
pluginone provider people connect, in its own folder
registrythe one list of plugins the app knows
OAuththe provider asks the person, then gives the app a token
consentthe provider's page where the person says yes
clientthe code that calls the provider's API
Pluginthe interface every provider fills in, plugins/base.py
OAuthProviderthe shared consent round: start URL, code for token, refresh
sealedencrypted with TOKEN_ENCRYPTION_KEY before it is stored
SourceError · NotWrittenthe provider failed · a write was refused; the tool turns either into a readable answer

Files to change, in order

#FileDo
1core/config.py<key>_client_id, <key>_client_secret; a line in .env.example
2plugins/jira/client.pyplugins/<key>/client.py: the provider's REST calls on one person's token; raise SourceError / NotWritten from plugins/errors.py
3plugins/jira/oauth.pycopy into plugins/<key>/oauth.py: an OAuthProvider, connect, token_for
4infra/postgres/repositories/accounts.pyan account table and a migration: the sealed refresh token per person
5plugins/jira/plugin.pycopy into plugins/<key>/plugin.py: every Plugin member, then PLUGIN = …()
6plugins/registry.pyadd it to PLUGINS
7web/src/components/panels/Connections.tsxoptional: an icon in ICONS
testtests/test_plugin_tools.pyno client → no tools; GET /connections lists it (tests/test_auth.py)

Easy to get wrong

MistakeResult
tool module imported at the top of plugin.pytests/test_layers.py fails: api would import agents
client imports anything but core, infra.http or plugins/errors.pytests/test_layers.py fails: a client only talks to the provider
callback put under /connectionskeep it at /auth/<key>/callback: that is the uri the provider has registered
a shared token in .env for the syncagainst the design: every read is on a person's own grant
first sync queued without a trya broker hiccup shows "failed" though the account is saved; log it, the timer syncs
