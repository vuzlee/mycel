Operate

Run and fix it

  • Every command goes through scripts/stack.sh
  • When something is wrong, run doctor first
Why
  • One script for every start, stop and check, so dev, compose and Kubernetes behave alike
  • doctor first: most problems are a store not up or a key not set

TrapWhat happens
