Operate

First-time setup

  • An admin does it once per deployment; each person then connects their own accounts
  • .env holds only what hosting needs — nothing belongs to one person
Why
  • Mycel signs people in and reads their accounts through OAuth apps registered once per deployment
  • Secrets for the host only; each person's tokens come from their own consent

Words

WordMeans
OAuth appwhat you register at Google or Atlassian so people can connect
redirect URIwhere the provider sends a person back; must match exactly
.enva file of the host's settings and secrets, never in git; nothing personal → Config
gateway (LiteLLM)one door to every host model; holds the provider keys, counts and caps spend → Model and cost
gateway keythe app's key to LiteLLM, made once
scopeone permission the app asks the provider for

1 · Jira OAuth app, for "Connect Jira"

StepWhereDo
1developer.atlassian.com/console/myappsCreate → OAuth 2.0 integration
2Permissions → Jira APIread:jira-work, read:jira-user, write:jira-work, offline_access; with jira_manage_sprints on (dev) also read:board-scope:jira-software, read:sprint:jira-software, write:sprint:jira-software; with jira_allow_create_project also manage:jira-project
3Authorizationcallback <PUBLIC_BASE_URL>/auth/jira/callback
4Settings → .envJIRA_CLIENT_ID, JIRA_CLIENT_SECRET

2 · Google OAuth client, for "Connect Google"

StepWhereDo
1console.cloud.google.coma project; enable Google Calendar API and Gmail API
2OAuth consent screenscopes openid, email, calendar.events, gmail.readonly
3Credentials → OAuth client ID → Webredirect <PUBLIC_BASE_URL>/auth/google/callback
4.envGOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET

3 · Models

StepDo
editconfig/litellm/models.yaml (in git, no keys); keep the providers you have
listhost_models in config/environments/base.yaml: the names people may pick; exactly one default: true
keysDEFAULT_MODEL_API_KEY=a,b in .env; the gateway splits it into _1, _2
gateway keyset LITELLM_MASTER_KEY in .env, start the stack (compose), then scripts/stack.sh gateway-key; paste the line it prints into .env as LITELLM_API_KEY. Without it every answer fails

4 · The rest of .env

KeyWhat
TOKEN_ENCRYPTION_KEYencrypts every stored refresh token; python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"; to rotate, put the new key first, comma, the old one; replacing it disconnects everyone
SMTP_HOST · SMTP_FROM · SMTP_USERNAME · SMTP_PASSWORDsender of the sign-in code mail (Gmail: smtp.gmail.com + an app password); unset → only Google sign-in, the doctor MAIL line says so
PUBLIC_BASE_URLin config/environments/; the address people reach the app at; every OAuth callback is built from it
