First-time setup

  • An admin does it once per deployment; each person then connects their own accounts
  • .env holds only what hosting needs — nothing belongs to one person

1 · Jira OAuth app, for "Connect Jira"

StepWhereDo
1developer.atlassian.com/console/myappsCreate → OAuth 2.0 integration
2Permissions → Jira APIread:jira-work, read:jira-user, write:jira-work
3Authorizationcallback <PUBLIC_BASE_URL>/auth/jira/callback
4Settings → .envJIRA_CLIENT_ID, JIRA_CLIENT_SECRET

2 · Google OAuth client, for "Connect Google"

StepWhereDo
1console.cloud.google.coma project; enable Google Calendar API and Gmail API
2OAuth consent screenscopes calendar.events, gmail.readonly
3Credentials → OAuth client ID → Webredirect <PUBLIC_BASE_URL>/auth/google/callback
4.envGOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET

3 · Models

StepDo
editconfig/litellm/models.yaml (in git, no keys); keep the providers you have
nameeach model_name is what config/agents/*.yaml asks for as cloud:<model_name>
keysput the keys it names in .env

4 · The rest of .env

KeyWhat
TOKEN_ENCRYPTION_KEYencrypts every stored refresh token; python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"; rotating it disconnects everyone
SMTP_HOST · SMTP_FROM · SMTP_USERNAME · SMTP_PASSWORDsender for password-reset mail (Gmail: smtp.gmail.com + an app password); unset → reset is off and doctor says so
PUBLIC_BASE_URLin config/environments/; the address people reach the app at; every callback and reset link is built from it
