Core types: the few values every layer passes around

Who is asking, what a turn cost, which sources are on, and the errors Mycel raises on purpose. They live in core/, which imports nothing else.

01 · The types

  • id : int
  • email : str
  • route → current_user → job → agents → plugins

  • model_ref : str
  • tokens_in, tokens_out : int

  • knowledge · web · jira
  • calendar · mail

02 · Errors

Key insight: catching MycelError means "an expected failure, say it plainly"; anything else is a bug and is logged with its trace.

Details
  • Agent failures (DegenerateLoop, ModelAuth…) live in agents/core/exceptions.py; how the worker sorts them: Processes.

03 · Chips filter tools

Every toolset is tagged with the chips that open it; a turn sees only tools its chips open.

chips = None
every tool offered
chips = {} (all off)
no tool offered; the orchestrator says which sources are off
A tool with no chip tag
never offered once chips are set

Guaranteed / not guaranteed

Guaranteed

  • Types are frozen: a Principal cannot change mid-job
  • Unknown chip names from a job are dropped, not trusted

Not guaranteed

  • Every MycelError subclass lives in core/: layers add their own
