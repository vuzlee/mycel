Mycel handbook / Overview / Code map

Where code lives, and which way imports may point

Each folder has one job. Lower layers never import higher ones, and a test fails the build if one does.

01 The layers02 Every folder03 Rules a test enforcesVocabulary

01 · The layers

Imports point down. A box may use anything below it, never above.

Key insight: worker.py and lifecycle.py sit at the root because each wires every layer; inside one they would import upward.

Details
  • observability/, doctor/ and mcp/ sit beside the layers: called at start-up or by hand, not on the request path.
  • devtools/ is never imported by the app.
