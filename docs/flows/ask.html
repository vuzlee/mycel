Flow

Ask a question

  • One question, from the chat box to the stored answer
  • Read this before the other flows: they each zoom into one part of it
  • Hover a box for its file · click to open it
Why
  • An answer takes seconds to minutes and can fail halfway
  • So the API saves the question, queues a job and returns at once; a worker answers and streams each step back

Words

WordMeans
turnone question and its answer
job · queue · workera unit of slow work · RabbitMQ holding it · the process that runs it
outboxa table of jobs waiting to be sent; the row is written in the same commit as the data, so a crash cannot lose the job → Architecture
agenta model with a prompt and tools it may call; the orchestrator hands parts of a question to specialists → Architecture
orchestrator · specialistthe agent that reads the question and merges the answer · an agent it hands one part to (analyst, researcher)
SSEserver-sent events: the server pushes each change to the browser as it happens → Architecture
