Flow

Own model

  • A person adds their own endpoint and keys
  • Calls go straight to it, not through the gateway
  • Hover a box for its file · click to open it
Why
  • Some people have their own model or key, or must keep data off the shared gateway
  • A user-typed URL could reach inside the network, so it is checked on save and before every call

Words

WordMeans
own modelan endpoint and keys a person adds; calls skip the gateway → Model and cost
endpointthe URL of a model API
