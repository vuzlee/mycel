Flow

Use your own model

  • A person adds their own endpoint and keys
  • Calls go straight to it, not through the gateway
  • Hover a box for its file · click to open it

Key facts

WhatValue
limits10 models per person · 1–5 keys each · 6 key tests a minute
URLhttps only (plain http only for allowed LAN hosts) · no private or internal address · checked on save and before every call
keysencrypted with TOKEN_ENCRYPTION_KEY · only the last 4 characters are shown
key ordera key that gets 401/402/403/429 is set aside; the next key is tried
cost capnone — own model calls bypass the gateway's budget
