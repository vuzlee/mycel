Flow

Traces, metrics, logs, events

  • Where to look when an answer is slow, costly or wrong
  • Six outputs: traces, metrics, logs, alerts, live events, doctor
  • Hover a box for its file · click to open it
Why
  • An answer can be slow, costly or wrong in many places: API, queue, worker, model, tool
  • Each output answers one question: what happened (trace), how much (metric), why (log)

Words

WordMeans
trace · spanone turn's tree of steps · one step in it, with time and tokens

doctorscripts/stack.sh doctor: reports what is set up, broken or off; run it first → Config
