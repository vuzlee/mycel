Flow

Sign in

  • Two ways in: C = a code sent by mail, G = Google
  • C1–C4 or G1–G5, then 1–3: account, session row, a 14-day cookie
  • Hover a box for its file · click to open it
Why
  • The app must know who asks before it reads anyone's Jira or mail
  • No password is stored: Google or a mailed code proves the address

Words

WordMeans
session cookiea random id the browser sends with every request; the server looks up who it is
Google sign-inGoogle confirms the address; the app never sees a password
state · nonceone-time random values that tie the provider's answer to the start, so a forged one is refused
SMTPthe protocol that sends mail
httponly · secure · samesitethe cookie is hidden from scripts · sent only on HTTPS · not sent from other sites
one callbackGoogle allows one redirect per client; sign-in and connect share it, the state tells them apart
