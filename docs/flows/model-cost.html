Flow

Model and cost

  • Each turn picks one model, and every agent of the run calls it
  • Every call is priced; a job stops at $0.50
  • Hover a box for its file · click to open it
Why
  • Every call costs money, and an agent loop can call many times
  • A ceiling per job and a cap per day stop a runaway before the bill does

Words

WordMeans
host modela model the deployment provides through the gateway; one is the default → Config
own modelan endpoint and keys a person adds; calls skip the gateway
gateway (LiteLLM)one door to every host model; holds the provider keys, counts and caps spend
budgetthe most one job may spend on models: $0.50; what is left shrinks with each call
usagetokens in and out of a call; priced into dollars
UsageLimitspydantic-ai's cap on tokens per run
