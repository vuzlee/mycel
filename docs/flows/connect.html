Connect an account

  • Each person connects their own Jira or Google
  • The same routes serve every plugin
  • Hover a box for its file · click to open it

Key facts

WhatValue

routes/connections/{key}/start · /auth/{key}/callback (registered with the provider) · DELETE /connections/{key} · GET /connections
