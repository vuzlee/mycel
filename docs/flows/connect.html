Flow

Connect an account

  • Each person connects their own Jira or Google
  • The same routes serve every plugin
  • Hover a box for its file · click to open it
Why
  • Mycel reads Jira and Gmail as the person, so it sees only what they may see
  • The provider never gives the app a password, only a token it can renew

Words

WordMeans
OAuththe provider asks the person, then gives the app a token, never the password
consentthe provider's page where the person says yes
state · nonceone-time random values that tie the provider's answer to the start, so a forged one is refused → Sign in
callbackthe URL the provider sends the person back to, with a code
codea one-time ticket the provider sends back; swapped for tokens
refresh tokena long-lived key per person and provider, traded for short access tokens; the one thing stored, sealed → First-time setup

Key facts

WhatValue
routes/connections/{key}/start · /auth/{key}/callback (registered with the provider) · DELETE /connections/{key} · GET /connections
stateRedis, 10 min, used once; only the account that started may finish
tokenrefresh token encrypted with TOKEN_ENCRYPTION_KEY; Jira replaces it on each refresh
Googleplugins/google/: same path without steps 9–10 (no access, no sync); its tools go to the researcher; sign-in shares /auth/google/callback
back to the page/app/?settings=accounts&jira=connected (or jira_error=…): Settings opens on Accounts
