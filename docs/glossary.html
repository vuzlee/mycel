analystthe agent that answers questions over data → Add a tool
apppeople, sessions, chats, connections → Database

AZ (availability zone)one data centre in the region; EKS wants two → On AWS (EKS)
BaseHTTPMiddlewareStarlette's easy middleware; it buffers the whole response, which breaks streaming → Architecture
broker · RabbitMQthe queue server that holds jobs for workers → Outbox
bronze · silver · goldraw copy from the provider · cleaned rows, one table per source · the one joined shape agents and charts read, whatever the source → Architecture
budgetthe most one job may spend on models: $0.50; what is left shrinks with each call → Model and cost
callbackthe URL the provider sends the person back to, with a code → Connect an account
chipa source the person ticks under the chat box (Jira, Mail, Knowledge…); tools open only for picked chips → Add a tool
chunkone piece of a document, a few paragraphs → Upload a document
claima short Redis key: only one worker runs this job now → Idempotency
clientthe code that calls the provider's API → Add a plugin
codea one-time ticket the provider sends back; swapped for tokens → Connect an account
commit · transactionthe moment a group of writes becomes permanent, all or none → Outbox
consentthe provider's page where the person says yes → Connect an account
contextvarsper-task variables in Python; they do not cross into another process → Architecture
credits$100 AWS gave the account; pays bills until 2027-10. Budgets count before them, so a real cost still shows → On AWS (EKS)
dead-letter queuejobs.dlq · ingest.dlq: where a job parks after its last try, until someone replays it; a job there is "parked" → Job failures
delivery counthow many times this job was handed over again (redelivered); too many → dead-letter → Idempotency
dev · compose · k8sapp on the host · all in containers · on minikube → Run and fix it
doclingthe library that reads PDF and DOCX into text → Upload a document
doctorscripts/stack.sh doctor: reports what is set up, broken or off; run it first → Config
EC2 · nodea rented virtual machine · here the one machine the pods run on → On AWS (EKS)
EKSKubernetes run by AWS: AWS keeps the control part, you rent the machines → On AWS (EKS)
embed · vectorturn text into numbers by meaning, so it can be searched · those numbers → Jira sync
emptyDira pod's scratch folder, gone with the pod: nothing is kept between sessions → On AWS (EKS)
endpointthe URL of a model API → Own model
.enva file of the host's settings and secrets, never in git; nothing personal → Config

estimate vs spenthours planned against hours logged → Dashboard
ETLextract, transform, load: the steps that turn bronze into gold → Architecture
evalsgolden questions with known answers, run by hand against real models → Architecture

Fernetthe encryption format TOKEN_ENCRYPTION_KEY is a key for → First-time setup
FINAL · TRANSIENTa failure retrying cannot fix · one it may → Job failures
gateway (LiteLLM)one door to every host model; holds the provider keys, counts and caps spend → Model and cost

httponly · secure · samesitethe cookie is hidden from scripts · sent only on HTTPS · not sent from other sites → Sign in

INDEX_GOLDthe job that embeds new gold rows for search → Jira sync
ingestread a file, split it, make it searchable → Upload a document

inject() · extract()OpenTelemetry: write the trace ids into message headers · read them back in the worker → Architecture
Internet Gatewaythe VPC's free door to the internet, both ways → On AWS (EKS)
job · queue · workera unit of slow work · RabbitMQ holding it · the process that runs it → Ask a question
JQLJira's query language; here: issues changed since the last run → Jira sync
JSONB · timestamptzJSON stored so Postgres can query inside it · a time with its zone → Database

kubectlthe command line for Kubernetes → On AWS (EKS)
Kubernetes · podruns and restarts containers on a cluster · one running copy of a program → Run and fix it
Lambda · SNSa function AWS runs on a schedule · a topic that sends mail → On AWS (EKS)
Langfusewhere traces are read: one trace per turn → Traces and metrics
Last-Event-IDthe browser's place in the stream, so a reconnect resumes → Traces and metrics
LB controllera pod that reads the app's Ingress and makes the ALB for it → On AWS (EKS)

Lokistores container logs, searched in Grafana → Traces and metrics
max_connectionsthe most connections Postgres accepts, from all processes together → Architecture
MCPModel Context Protocol: a standard way to call tools that live on another server → Architecture

minikubea one-machine Kubernetes on your laptop → Run and fix it
MinIOfile storage, S3-compatible; keeps the original upload → Upload a document

mycel-errorthe message header that says why a job was parked → Traces and metrics
mycel-session · mycel-expirestags: this resource belongs to a session · the time the reaper may delete it → On AWS (EKS)
mycel_readerthe database user agent queries run as: reads gold, only the asker's projects → Architecture
NATa paid gateway (~$0.05/h + data) for private machines to reach out; skipped: the node sits in a public subnet with its own IP → On AWS (EKS)
