What Mycel is, in one line

  • A chat app: you ask in plain words, AI agents answer from your Jira, Gmail, Calendar and uploaded documents
  • Today it runs on a laptop; this plan puts the same thing on Amazon's cloud (AWS)

5 · Why it is shaped this way

ChoiceInstead ofBecause
Stores as containers in the clusterRDS, ElastiCache, Amazon MQ · or a second EC2no extra machine, no managed-service price, all of it on EKS
emptyDir, no disks for dataEBS volumes (PVC)data is not kept, so nothing is left to clean up
kubectl port-forwarddomain + load balanceronly the owner uses it; Google and Jira accept a localhost callback, already registered
Public subnets, no NATprivate subnets + NATNAT is the largest avoidable cost; no port on the node is open
MinIO, Docker HubS3, ECRboth already work; S3 needs a code change (region fixed to us-east-1)
Traces without contentprompts and answers in Langfusereal mail and Jira would leave for Langfuse Cloud; the trace tree, tokens and cost stay
Delete the cluster each timestop the EC2 onlyEKS bills $0.10/h while it exists, node or not
