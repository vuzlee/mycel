02 · How it works

Every core caller asks the registry; each provider is one folder.

Key insight: tool modules load inside toolsets(), so api imports plugins without importing agents (tests/test_layers.py).

Details
  • Callback paths are unchanged (/auth/google/callback, /auth/jira/callback): no re-registration at the providers.
  • Google sign-in shares the Google callback; google_signin.is_signin(state) tells them apart. Sign-in is identity, not a plugin.
  • auth.router is included first, so /auth/me and /auth/methods win over /auth/{key}.
  • Tests: test_plugin_tools.py, test_sync_job.py, test_sync_readers.py, test_auth.py.

05 · Guaranteed / not guaranteed

Guaranteed

  • Every provider's data is read on a person's own grant
  • One sync per plugin at a time
  • A plugin with no client offers no tool

Not guaranteed

  • A Jira project nobody connected can browse is never synced
  • The interface fits a third provider unchanged: it was drawn from two
